# Just Monitor Control

Плагин Stream Deck для Windows. Управляет яркостью монитора, видеовходом, частотой обновления, HDR и сном.

## Возможности

| Действие | Описание |
| --- | --- |
| Яркость | Можно задать точный уровень, шаг вверх или вниз, переключиться между двумя сохранёнными состояниями сразу на нескольких мониторах. |
| Переключение входа | Переключайся на определенный порт или между двумя, например DisplayPort и HDMI. |
| Изменение частоты обновления | Частоты, которые сообщает Windows, включая точные режимы вроде 59,94 Гц. |
| HDR | Включение и выключение HDR на одном мониторе или на всех выбранных. |
| Сон и пробуждение | Сон выбранных мониторов или всего рабочего стола, а затем пробуждение. |
| Raw VCP | Любой код и значение VESA VCP для функций, у которых нет своей кнопки. |
| Опознать экраны | На каждом экране ненадолго появляется номер, чтобы сопоставить названия выпадающего меню с реальными мониторами. |

## Требования

- **Программа Elgato Stream Deck**: версия 6.9 или новее.
- **Система**: Windows 10 (1809 или новее) или Windows 11.
- В меню монитора включён DDC/CI.
- Прямое подключение по DisplayPort или HDMI. Часть USB-C концентраторов и пассивных переходников не пропускает команды к монитору.

## Установка

1. Скачайте последнюю версию со страницы [Releases](https://github.com/valentderah/stream-deck-just-monitor-control/releases).
2. Дважды щёлкните скачанный файл `.streamDeckPlugin`, чтобы установить плагин.
