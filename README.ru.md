# Just Monitor Control

Плагин Stream Deck для управления мониторами в Windows: яркость, источник видео, частота обновления, HDR и сон.

## Возможности

| Действие | Описание |
| --- | --- |
| Яркость | Задать точный уровень, изменить его на шаг или переключаться между двумя сохранёнными уровнями. Можно менять сразу несколько мониторов. |
| Переключение входа | Переключить монитор на выбранный порт или переключаться между двумя портами, например DisplayPort и HDMI. В режиме переключения кнопка меняется только после того, как монитор подтвердит новый вход. |
| Частота обновления | Переключение между частотами, которые сообщает Windows, включая точные режимы вроде 59,94 Гц. |
| HDR | Включить или выключить HDR на одном мониторе или на всех выбранных. |
| Сон и пробуждение | Усыпить выбранные мониторы или весь рабочий стол и снова их разбудить. |
| Raw VCP | Отправить произвольный код и значение VESA VCP для настроек, у которых нет отдельной кнопки. |
| Определение мониторов | Показать временный номер на каждом экране, чтобы сопоставить кнопки с физическими мониторами. |

## Требования

- **Elgato Stream Deck**: версия 6.9 или новее.
- **Операционная система**: Windows 10 (1809+) или Windows 11.
- В меню монитора включён DDC/CI.
- Прямое подключение через DisplayPort или HDMI. Некоторые USB-C хабы и пассивные переходники блокируют управление монитором.

## Установка

1. Скачайте последнюю версию на странице [Releases](https://github.com/valentderah/stream-deck-just-monitor-control/releases).
2. Дважды щёлкните скачанный файл `.streamDeckPlugin`, чтобы установить плагин.
